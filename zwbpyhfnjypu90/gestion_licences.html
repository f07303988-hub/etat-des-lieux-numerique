Gestion des licences

Ajoute ou révoque des communes, puis republie licences.json à l'endroit où l'application est hébergée. Tout se calcule ici, sur cet appareil — rien n'est envoyé nulle part.

4. Publier la liste mise à jour

À enregistrer sous le nom licences.json, à la racine de l'hébergement de l'application (à côté d'index.html).

{"licenses":[]}

Où est-ce que je dépose licences.json ?

Exactement au même endroit qu'index.html, dans le même dossier. L'application le cherche juste à côté d'elle-même (./licences.json) — si tu le mets ailleurs, elle ne le trouvera pas.

Comment ça révoque une commune ?

En retirant son code de la liste (bouton "Révoquer" à côté de son nom) puis en republiant licences.json. Son application le remarque à la prochaine fois qu'elle a du réseau, et se reverrouille — sans toucher aux autres communes.

Et si la commune n'a pas de réseau sur place ?

L'application continue de fonctionner avec le dernier statut connu tant qu'elle n'a pas pu vérifier en ligne. Elle se reverrouillera dès qu'elle aura à nouveau une connexion.

Comment renouveler une commune pour une nouvelle année ?

Rien à faire ici : la commune ressaisit simplement son code existant dans l'application (depuis l'écran de blocage, ou à tout moment dans Configuration). Ça repousse son échéance d'un an, sans toucher à licences.json — tant que son code n'a pas été révoqué, il reste valable pour un renouvellement.

Deux communes peuvent-elles avoir le même code ?

Techniquement oui, mais évite : tu ne pourrais plus révoquer l'une sans révoquer l'autre en même temps, puisque l'application ne vérifie qu'une empreinte, pas l'identité de la commune. Un code par commune, toujours.

Je perds un code généré ici avant de le donner à la commune, grave ?

Pas du tout, tant que tu n'as pas republié le fichier avec son empreinte. Retire l'entrée (Révoquer) et recommence.

J'ai oublié le code que j'ai donné à une commune, comment le retrouver ?

Impossible à partir de l'empreinte (fait exprès, comme un mot de passe). Note toujours le code quelque part de fiable au moment où tu le donnes — un tableur avec commune, date et code suffit. En dernier recours, révoque son entrée et donne-lui un nouveau code : elle ré-active avec, sans perdre ses données.

Je perds mon fichier licences.json, je fais comment ?

Recolle ici la dernière version que tu as pu sauvegarder de ton côté (email envoyé, sauvegarde de fichier...). Si tu n'as vraiment plus aucune copie, il faudra régénérer un nouveau code pour chaque commune et le leur redonner — leurs données sur place ne sont pas affectées, seule la vérification de licence doit être refaite.
